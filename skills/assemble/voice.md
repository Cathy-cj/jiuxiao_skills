# TTS 逐字稿规则

本分册规定 `class.json` 里所有 `tts_text` 的写法。`tts_text` 是**要被合成成语音、直接播给学生听的逐字稿**，不是屏幕文案：凡是学生只能看见、听不出来的写法，一律不能出现。

## 适用范围

| 适用 | 不适用 |
| --- | --- |
| `begin_guide_data.tts_text` | `learning_objective`、`core_method` |
| `feiman_guide_data.tts_text` | `feiman_data[].question` / `answer` |
| `homework_guide_data.tts_text` | `week_question_data[]`、`homework_data[]` 的题干答案解析 |

题目、答案、解析、费曼讲法稿是屏幕文本，保留原题的阿拉伯数字与算式写法，**不要**按本分册改写。本分册只管三个 `tts_text`。

## 只写说得出口的字

`tts_text` 只能包含中文汉字、中文标点和英文字母。数字、公式、单位、数学符号一律写成中文读法。

| 屏幕上是 | 逐字稿写 | 不能写 |
| --- | --- | --- |
| `4.05` | 四点零五 | 4.05 |
| `405` | 四百零五 | 405 |
| `0.72` | 零点七二 | 0.72 |
| `85` | 八十五 | 85 |
| `$\frac{1}{3}$` | 三分之一 | 1/3、三分之1 |
| `$\frac{1}{3\times4}$` | 三乘四分之一 | 每三分之一乘四 |
| `1－\frac{1}{3}` | 一减三分之一 | （1－1/3） |
| `6×6×5＝180` | 六乘六乘五等于一百八十 | 6×6×5＝180 |
| `cm` / `km` / `cm²` | 厘米 / 千米 / 平方厘米 | cm、km、cm² |
| `30%` | 百分之三十 | 30% |

- **分数一律「分母分之分子」**：`$\frac{a}{b}$` 读「b 分之 a」，分子分母都写汉字，禁止倒置成「a 分之 b」。分母是运算式时先把分母整个读完再说「分之」。
- **英文字母原样保留**，不音译：`$a+b-c$` 写「a 加 b 减 c」，几何点名写 `ABD`，禁止「阿加贝减西」「艾克斯」。字母与汉字之间可留一个空格便于断句，不加引号。单位是例外，仍写汉字。
- **选项**用字母标记时直接读该字母加「选项」，如「a选项」到「d选项」；不说「第二项」，不把 A、B、C、D 改读成「甲、乙、丙、丁」，除非原题选项本来就是甲乙丙丁。

## 「两」和「二」

- 数量（多少个、多大）在百、千、万、亿前用「两」：两千、两百、两万、两亿。`2022` 作为数学量写「两千零二十二」。
- 序数、编号、月份、分数分子仍用「二」：第二、二月、二号、二分之一。
- 年份或编号习惯逐位念时写「二零二二」，不要用位权读法却写「二」。

## 标点与旁白

- **禁用直角引号「」**。需要强调时用弯引号“”，或直接写汉字不加引号。本课常出现的「单位1」，逐字稿写**单位一**（不加引号、不写阿拉伯数字），必要时写“单位一”。
- 不写括号说明、屏幕提示、动画指令、制作备注；`（　　）`、题号、分值、出处都不读。
- 不用列表符号、Markdown、换行排版；逐字稿是一段连续的话。

## 引导口播写什么

三个 `tts_text` 都是**做题前的引导**，不是答案讲评，也不是读题。

- **不逐字读题干**：题面在屏幕上。引导只说「怎么审这道题、先想清楚什么、按什么顺序动手」。需要指认题目里的某个量时，用它的名字说（「乘数十分位上那个数」「废纸的总质量」），不要把阿拉伯数字原样念出来；确实要念数时按上表写成汉字。
- **不给结论**：不说得数、不说该选哪个选项、不替学生做完推理。
- **称呼「同学」**，禁止「同学们」。
- 一段话只承载一个动手节奏，不要把多个步骤连读成长句串。

## 自动检查

写完 `class.json` 后运行：

```text
node tools/check-tts-voice.mjs <课节编码>/class.json
```

检查器扫描三类 `tts_text`，报出阿拉伯数字、直角引号「」、LaTeX 残留（`\`、`$`、`frac`）、数学符号（`×÷＝＋－%`）、单位缩写（`cm`、`km`、`ml` 等）、`同学们`、以及换行和 Markdown 标记。检查器只能查形，读法是否顺口仍要自己念一遍。
