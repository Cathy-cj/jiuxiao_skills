# 费曼作业与 `#` 挖空

本分册把独立费曼 skill 的话术与挖空规则收进课节组装：产物仍是 `class.json` 的 `feiman_data` / `feiman_guide_data`，不另写一套 JSON，也不写 `grade`、`feynman_prompt`、`key_blanks` 等独立 skill 字段。

## 目标

费曼作业要学生**按课上的讲法，把这道练习题自己再讲一遍**。因此 `question` 是原题，`answer` 是这道题的**缩略讲法稿**：它复现课件教的那条解题主线，用「因为…所以…；又因为…所以…」把推理串起来，并在因果句里留出 `#` 挖空，由学生开口补上。

`answer` 不是题干的挖空版本，也不是完整解析的照抄。

> 挖空标记已由成对的 `$` 改为成对的 `#`。`$` 在本字段现在专门用作 LaTeX 定界符，不再表示挖空。旧稿里的 `$挖空$` 和一度用过的 `##挖空##` 都要改写成 `#挖空#`。

## 取题

费曼没有独立文件，只从当前班指定的星级 `courseware.json` 取 `problem_source` 中 `flow_id="flow_3"` 的练习题：

| 班型 | 指定星级 |
| --- | --- |
| B | 3star |
| A | 4star |
| AA | 5star |
| AAA | 6star |
| S | 8star |

指定星级目录或该 `flow_3` 缺失时，写：

```json
"feiman_data": [],
"feiman_guide_data": null
```

不上传的班型（见 [schema.md](schema.md)「班型取舍」）整体跳过，不为它写费曼。已经配齐并上传的班，即使前面有缺口，也仍写它指定星级的费曼。不得为缺失的费曼星级编造 `courseware.json` 或练习题。

同份课件里的例题（`flow_1`）只作方法措辞参考，**绝不**为例题另写一条费曼。

## 年级识别

年级只用来选话术，**不写入** `class.json`（`grade` 是禁止键）。按此优先级确定：

1. 用户明确指定的年级；
2. 课件 `title`、页眉或星级目录路径中的年级（如「一年级」「九年级」）；
3. `中考冲刺` 视为九年级；
4. 无法识别时先问用户，不能猜。

| 学段 | 表达重点 | 推荐长度 |
| --- | --- | --- |
| 一、二年级 | 看、数、画、比；一句观察、一句规则、一句结论 | 2–3 句 |
| 三至六年级 | 找信息、选方法、列关系、检查；规则先用白话再说名称 | 3–4 句 |
| 七至九年级及高中 | 条件→关系→推理→检验；必要的式子和中间结果都写全 | 3–5 步 |

高年级完整性优先于少符号、少数字。超长时只删重复表述或机械代入，目标、条件、定理、关键计算、推理转折和结论必须保留。去 `#` 与 `$` 定界后，整条 `answer` 不超过 500 字。

## 项目映射

```json
{
  "question": "<flow_3.stem 原文>",
  "answer": "<按课件讲法缩写的因果复述稿，含成对 # 挖空>",
  "image_url": ""
}
```

`question` 以 `flow_3.stem` 为底本：选项一并保留，不要拆出去。源 stem 里的 `![说明](本地文件)` 必须原样保留，不得因为还不是 http URL 就删掉。写入前只按 [schema.md](schema.md)「屏幕公式」做预览安全改写（字母前的 `<` 改成 `\lt`、区间写成 `\left[` / `\right]`、联立拆掉 `cases` / `\{`、表格改成规定的 `$$ array $$`），不得改题目条件和选项，也不得丢掉选项图。

`image_url` **恒为 `""`**，文本阶段和媒体阶段都不填。stem 里出现的每一张图（含选项图）都要进 `question`，不是只取 `images[0]`。媒体阶段由 `fill-media.mjs` 从 `<星级>/problem/` 上传这些文件，并把返回的裸 URL 写进 `question` 中图片原本出现的位置。只出现在 `answer_detail` 的解析图不要写进 `question`。图中无法从文本确认的编号、位置、数量，不得写成事实。

`stem` 以 `（ ）` 结尾却在 `problem_source` 里找不到选项时，说明选项只存在于禁读的 `nodes[]`：照原文写出 `question`，在交付摘要里点名这道题缺选项，**不得自己编选项，也不得为了取选项去读 `nodes[]`**。

## `answer`：缩略讲法稿

### 唯一可用素材

只用同一份 `courseware.json` 里的：

| 素材 | 用途 |
| --- | --- |
| `flow_3.answer_detail` | 讲法主线：分几步、每步做什么、算式怎么列 |
| `flow_3.answer_short` | 收尾的得数 |
| 顶层 `title` | 本课方法名，用于点出"这道题用的是什么方法" |
| `flow_1.answer_detail` | 同一套解法骨架的措辞参考，用来把主线补顺 |

不得引入课件没有的方法、条件、数据或结论；不得读取 `nodes[]`，不得取用其他课节或其他星级。`flow_3.answer_detail` 缺失时，用 `flow_1.answer_detail` 的骨架套本题数据；两者都缺则该班按上文写空值。例题只核方法，不得把例题的条件、数字或答案移进练习题讲法。

### 写法

- **因果链**：每条 `answer` 必须写成连续因果：`因为 A，所以 B；又因为 C，所以 D。` 低星也要保留「又因为…所以…」第二段，只减少挖空数。
- **可讲清的链**：先做什么或用什么方法 → 关键理由或推断 → 结论或检验。禁止改写题干、照抄完整解析、只报答案。
- **客观步骤句**：不写「我、你、我们、你们、他们、同学、请你」等人称或直接称呼。
- **中文因果**：只写「因为……，所以……」「由此可得……」「根据……可知……」。禁止 `∵`、`∴`。
- **算式一律写成 LaTeX**：数学公式包在成对 `$` 里，如 `$5+10=15$`、`$6\times6\times5=180$`。中文句子不要整句包进 `$`。不再写 `6×6×5＝180` 这类纯文本算式——运算符出现在 `$...$` 之外会被检查器拦下。反斜杠命令必须待在 `$` 内。字母前的比较用 `\lt`（`$-1\lt 2x-1\lt 1$`、`$g(1)\lt g(t)$`），区间用 `\left[` / `\right]`。题面若有表，只能用 [schema.md](schema.md) 规定的 `$$\begin{array}{|c|…|}\hline … \end{array}$$`；联立禁止 `\begin{cases}`。
- **有头有尾**：开头点出方法或第一步为什么先做它；结尾落到 `answer_short` 的得数。
- 绝不使用 `____`。
- 禁止「上述条件和推理都成立」「由此可以确定本题的结果是」等脱离题意的套话。

## `#` 挖空规则

- 成对 `#...#`，挖空标记是**单个** `#`，不是 `##`。
- **空缺数随费曼练习星级**：2–3 星 1 处，4–5 星 2 处，6–8 星 3 处。班型对应关系见上文取题表（B=3 星、A=4 星、AA=5 星、AAA=6 星、S=8 星）。
- **只挖因果**：每一处空都必须落在「因为」或「所以」所在的分句里，挖的是因或果中的关键部分（概念、判断、方法、公式片段、中间结论），不是整段因、整段果。
- 合格：`因为旋转前后#对应边相等#，所以可以建立等腰三角形。`
- 合格：`因为两条直角边相等，所以这两个三角形#全等#。`
- 不合格：`因为#两条直角边相等#，所以可以建立全等关系。`（整个原因被遮住）
- 不挖题干已给的原始数据、最后得数和连接性虚词；同一个理解点不重复挖。不要默认把最终答案放进空里。
- 每对 `#` 之间必须有内容，不得嵌套，不得跨句吞掉整段讲法。
- **公式挖空**：要挖的是一条数学公式时，把整条 LaTeX 连同它的 `$` 一起包进去，写成 `#$5+10=15$#`。
- 挖空里可以文字和公式混排，如 `#先算出 $5+1=6$ 种#`；但 `#` 必须落在 `$...$` **之外**，不能把一条公式从中间切断（`$5+1#=6$#` 这种写法非法）。
- `$` 在 `answer` 里只作 LaTeX 定界符，必须成对；`#` 只作挖空标记，也必须成对。两者互不兼职。
- 授权的写法示意仅展示标记方式，禁止把任何示意题写进实际课节产物。

## 自动检查

写完 `class.json` 后，在项目根运行：

```text
node tools/check-feiman-answer.mjs <课节编码>/class.json
```

检查器验证：`answer` 与 `question` 不同；含「又因为」；`#` 成对且空缺数与该班费曼星级一致；每对之间非空；空缺落在「因为 / 所以」分句里；`#` 没有落进 `$...$` 内部；`$` 成对；运算符没有裸露在公式外；反斜杠没有跑出 `$`；去标记后不超过 500 字；不含 `____`、旧式 `##`、`∵` `∴`、人称/称呼和套话模板。失败时回到 `flow_3.answer_detail` 重写讲法，不得靠删字数或加空话凑合。

字数只统计讲法本身：去掉 `#` 标记与 `$` 定界符，LaTeX 命令（`\times` 等）和花括号不计入，公式里的数字与运算符照计。

## 引导

有费曼题时，`feiman_guide_data.tts_text` 请"同学"按课上的讲法把这道题从头讲一遍，并明确提示要把挖空处补全说出来；措辞依据该班 `core_method`，不得写"同学们"。它是逐字口播稿，写法按 [voice.md](voice.md)：要指认题目里的某个量时用它的名字说，需要念数时写中文读法，禁止把题干里的阿拉伯数字、算式或 LaTeX 抄进来。注意 `answer` 本身是屏幕文本，公式按上文写成 `$6\times6\times5=180$` 这样的 LaTeX，不适用逐字稿规则。`audio` 在文本阶段先写 `""`，媒体阶段用该 `tts_text` 调用 TTS 后写入返回的 URL。
